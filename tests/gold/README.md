# صفحات المرجع للقياس

كل صفحة لها ثلاثة ملفات بالرقم نفسه:

| الملف | ما فيه |
|---|---|
| `NN.pdf` | الصفحة وحدها، منسوخة من كتابها بلا تغيير |
| `NN.png` | صورتها، للمراجعة |
| `NN.txt` | نصها الصحيح كما في الصورة، مكتوبًا يدويًّا |

ووصف كل صفحة (كتابها ورقمها ونوعها) في `pages.json`.

## قواعد كتابة النص الصحيح

- اكتب ما في الصورة حرفًا حرفًا، بإملاء الطبعة نفسها، ولو خالف الإملاء الحديث (مثل «اسماء» و«فى» في الطبعات القديمة).
- اكتب المتن، ثم الحواشي في آخره، كل سطر حاشية في سطر.
- **لا تكتب** رقم الصفحة، ولا الرأس أو الذيل المتكرر في كل صفحة (مثل اسم الكتاب أو اسم الموقع)، ولا أرقام الأسطر في الهامش.
- أرقام الحواشي تُكتب بعد الكلمة كما في الصورة: `العكبري(2)`.
- الحركات اختيارية، فالقياس يحذفها، وكذلك علامات الترقيم.
- لا يحذف القياس الفرق بين الهمزات ولا بين الياء والألف المقصورة ولا التاء المربوطة: فهذه أخطاء تُحسب.

## الصفحات الحالية

نصوصها كتبها Claude من الصور، ويراجعها المطوّر. ولا تُنشر هذه الصفحات في المستودع العامّ لحقوق كتبها؛ فمن أراد القياس وضع صفحاته هنا بالصيغة نفسها. والصفحة `09` رديئة الطباعة، فقد يكون في نصها كلمات مشكوك فيها.

## التشغيل

```
.venv\Scripts\python.exe tests\measure.py --diff baseline
```

وقياس تعليم الكلمات المشكوك فيها (القاموس وحده، والقاموس مع السياق) بعد بناء القاموس:

```
.venv\Scripts\python.exe app\maktaba.py lexicon
.venv\Scripts\python.exe tests\measure_marks.py --save اسم
```
